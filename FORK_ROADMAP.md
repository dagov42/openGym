# Fork roadmap

Status: the fork's living plan. Nothing here is a promise; the specs in `docs/superpowers/specs/`
carry the detail. The upstream roadmap stays in [ROADMAP.md](ROADMAP.md); this file is the fork's
own order and version policy.

- Fix history: [FORK_CHANGELOG.md](FORK_CHANGELOG.md)
- Fork versioning: [FORK_VERSIONING.md](FORK_VERSIONING.md)
- Specs index: `docs/superpowers/specs/2026-11-16-feature-plan-index.md`

Current release: **v1.4.7** is tagged at `f3fc04047` (versions aligned, tests-ok and Release check
green). The GitHub release and its APKs are still to be built and uploaded on the release machine;
until then the in-app updater does not see it.

## План фич

Живой список: что делаем, что кандидаты, что сознательно отложено. Порядок важнее дат:
сначала маленькое и проверяемое, потом крупное. Обновляется по мере обсуждения.

**Спеки и открытые вопросы:** `docs/superpowers/specs/2026-11-16-feature-plan-index.md`
(шесть согласованы — поиск по History, What's new, недавние рутины, шорткаты, длительность и пауза
плана; остальные — кандидаты и задачи).

### Принципы

- Не дублировать очередь upstream: перед стартом проверить открытые PR (#702, #509, #706,
  #610, #1207 и серию watch-драфтов).
- Один PR — одна фича. Логика в `frontend/src/lib` — чистыми функциями с тестами рядом.
- Не добавлять поля в `S`, если значение выводится из истории: sync, бэкапы и API остаются
  нетронутыми.
- Новые области — за модулем (`docs/MODULES.md`), новые строки — через `t()`.
- Local-first, без телеметрии и без обязательных внешних вызовов.

### Порядок

1. **Поиск по History** — согласован, следующая реализация.
2. **What's new** — авто-шит раз за версию + ряд в Settings.
3. **Недавние рутины** — в Start picker, по времени последней тренировки.
4. **Шорткаты** — `?`, `/`, Esc и существующие клавиши тренировки.
5. **Оценка длительности** — согласована.
6. **Асимметрия L/R** — дешёвая аналитика из уже логируемых per-side данных; заодно даёт базу
   для режима травм («левая слабее на 12 %»).
7. **Подсказка отдыха по RIR/RPE** и **номер шкафчика** — мелкие улучшения, пока идёт работа
   над крупным.
8. **Режим «травма / боль»** — самая уникальная пользовательская фича; требует новых полей и
   правил sync.
9. **Пауза плана** — отпуск/болезнь без сломанной ротации, прогрессии и streak.
10. **Предпросмотр бэкапа + «Проверка данных»** — доверие self-hosted аудитории.
11. **Каталог-audit + тестовая гигиена** — меньше повторяющихся багов и быстрее чужие PR.
12. **`fork-status`** — ускоряет синхронизацию с upstream.
13. Кардио-рекорды, мастер CSV, журнал sync — по обратной связи.
14. Native/часы — когда есть девайс под рукой.

### Согласовано, следующая реализация

- [ ] **Поиск по History** — строка поиска, чипы All / Workouts / Notes / Recovery / Activities,
      фильтр месяца и «только PR». Глубокий поиск: название и заметки тренировки, имена упражнений
      (локализованные и английские), заметки подходов, зал, дневные заметки, recovery, активности.
      Без новых полей в `S`. Спека: `docs/superpowers/specs/2026-11-16-history-search-design.md`.

- [ ] **What's new после обновления** — авто-шит один раз на версию с 3–5 пунктами и ссылкой на
      changelog, плюс постоянный ряд в Settings → About & updates. Первая установка молчит. Спека:
      `docs/superpowers/specs/2026-11-16-whats-new-design.md`.

- [ ] **Недавние рутины в Start picker** — до пяти рутин по времени последней тренировки, без
      дублей с «Today». В упражнениях остаётся «Chosen» по частоте. Спека:
      `docs/superpowers/specs/2026-11-16-recent-routines-design.md`.

- [ ] **Шорткаты** — `?` открывает список, `/` фокусирует поиск текущего экрана, Esc закрывает
      шит; клавиши тренировки остаются. Без буквенной навигации. Спека:
      `docs/superpowers/specs/2026-11-16-keyboard-shortcuts-design.md`.

- [ ] **Оценка длительности тренировки** — «≈55 мин» на строке рутины и дня в Plan, в превью
      перед стартом. Гибрид: медиана последних 5 завершённых сессий этой рутины (минимум 2),
      иначе расчёт по плану (подходы, отдых, кардио, warm-up, superset). Комбинированный день —
      точная история набора или сумма. Без новых полей в `S`. Дизайн согласован 2026-11-16;
      спека будет в `docs/superpowers/specs/`. Фаза 2 (потом): Home/виджет и режим «у меня
      N минут».

### Кандидаты: пользовательские

- [ ] **Режим «травма / боль»** — флаг упражнения с заметкой и сроком, предупреждение в
      тренировке, автозамена из backup-упражнений, пауза прогрессии, контекст для Coach/MCP.
      Есть `dayNotes 'injured'` и `session-noprog`, но не на уровне упражнения. Средний объём.
- [ ] **Асимметрия L/R** — график и флаг разницы сторон по уже логируемым per-side данным.
      Новых данных не нужно; полезно для реабилитации и профилактики. Малый-средний.
- [ ] **Подсказка отдыха по RIR/RPE** — «+30 с?» после подхода, оценённого в RIR 0. Opt-in,
      только предложение, таймер не меняется сам. Малый.
- [ ] **Кардио-рекорды и темп** — лучшая средняя скорость/дистанция, тренд темпа, время в
      пульсовых зонах по уже сохраняемым avg/max HR. Оговорка: без per-second сэмплов «PR на
      5 км» не считается, только лучшие сессии/отрезки. Средний.
- [ ] **Номер шкафчика на карточке check-in** — issue #1096, ждёт реализации. Малый.
- [ ] **Пауза плана** — отпуск/болезнь: не ломать ротацию, прогрессию и streak на N дней.
      Есть day notes и rest days, но явной паузы нет. Малый-средний.
- [ ] **Один подход без каскада** — изменить вес одного рабочего подхода, не задевая
      следующие (issue #1166). Малый, уже просили.

### UX-находки из закрытых issues (2026-11-16)

Разобраны 400 самых обсуждаемых закрытых items (234 issue, 166 PR), 300 недавних закрытий и 300
закрытых PR. Важно: закрытый PR здесь часто значит «мейнтейнер применил вручную», а не «отклонено»,
поэтому такие PR не считаем отклонёнными идеями. Повторяющиеся классы: возврат/навигация,
случайные жесты, первый тап у асинхронных кнопок, переполнение на узких экранах, разрастание
настроек, обратная связь Coach, дубли после импорта. Всё ниже проверено на отсутствие в открытых
issues/PR и roadmap.

- [ ] **Корзина / Recently deleted** — тренировки, рутины и свои упражнения с восстановлением за
      30 дней; сейчас Undo живёт только в тосте (#558, #378, #283, #756). Средний.
- [ ] **Массовые действия в History** — выбрать несколько тренировок и удалить/экспортировать/
      перенести. Средний.
- [ ] **Setup doctor** — проверка установки: HTTPS, `/api/health`, совпадение `RP_ID`/`ORIGIN`,
      passkeys, push, расхождение часов, 403 прокси/Cloudflare. `/api/health` и `/api/config` уже
      есть (#329, #551, #741, #827, #870). Средний.
- [ ] **Diagnostics bundle** — «Скопировать диагностику» для багрепорта: версия, платформа, язык,
      модули, origin без секретов, последние ошибки, урезанный NetworkLog, счётчики состояния.
      Малый-средний.
- [ ] **Разбор дублей после импорта** — вероятные дубли (дата + рутина + подходы):
      объединить / оставить оба / удалить (#881, #784). Средний.
- [ ] **Недельный баланс плана** — подходы по мышцам против целей, две тяжёлые сессии подряд,
      нет дня отдыха, рутины не в плане; на `muscle-targets.js` и `recovery-hint.js`. Средний.
- [ ] **Глобальная палитра команд** — поиск по экранам, рутинам, упражнениям и действиям. Большой;
      имеет смысл после поиска по History и «недавних».

Снято после проверки кода:

- **Настройки жестов** — отдельный экран не нужен: #897 закрыт правилом скорости и посадки листа
  (`frontend/src/lib/sheet-dismiss.js`), #921 — отключённым shake-to-undo
  (`frontend/src/ios/App/App/AppDelegate.swift`), свайпы строк уже имеют переключатель.

### Данные и доверие

- [ ] **Восстановление из бэкапа с предпросмотром** — до подтверждения показать, что внутри:
      число тренировок, последняя дата, рутины, разница с текущим профилем. Плюс админская
      «Проверка данных» (битые строки, осиротевшие id, дубликаты). Средний.
- [ ] **Мастер импорта произвольного CSV** — сопоставление колонок для незнакомых выгрузок,
      предпросмотр 10 строк, сохранение подписи файла. Переиспользует `parseWorkoutRows`.
      Закрывает длинный хвост приложений. Средний-большой; сначала проверить, не проще ли
      добавить ещё один именованный импортер.
- [ ] **Видимость слияний sync** — журнал последних конфликтов/мержей (что и когда
      разошлось) в настройках или админке. Не автоматика, только доверие к sync. Средний.

### Каталог, i18n, качество

- [ ] **`scripts/catalogue/audit.mjs` + CI** — семантические проверки: имя ↔ мышцы/оборудование
      («calf raise» без икр, «curl» без сгибателей), кардио по имени/типу (класс #1296),
      дубликаты и опечатки, правила капитализации по локали (#1247). Вывод — CSV-очередь для
      контрибьюторов. Средний.
- [ ] **#1247 — русские названия** — Title Case/предлоги: сейчас CSS `capitalize` поднимает
      предлоги. Нужно решение на уровне данных или рендера. Малый, но требует UX-решения.
- [ ] **Регрессионные инварианты кардио и `assisted`** — уже частично закрыто в #1296/#1222;
      добить тестами, чтобы классификация не отъехала снова. Малый.
- [ ] **Тестовая гигиена** — 33 известных падения на Windows (NODE_ENV/act, ассеты, нативные
      исходники). Нужно либо починить, либо явно отделить environment-падения, чтобы CI и
      чужие PR не тонули. Малый-средний, но важен для скорости форка.

### Инфраструктура форка

- [ ] **`fork-status`** — скрипт сравнения `origin/main` и локальной ветки: какие upstream
      PR/коммиты ещё не забраны, какие конфликтуют, что уже перенесено. Уменьшает ручную
      работу с FORK_CHANGELOG. Малый.
- [ ] **Чек-лист синхронизации** — порядок: merge release → cherry-pick PR → локальные фиксы
      поверх PR → целевые тесты → запись в журнал. Оформить в `CONTRIBUTING` форка или здесь.
