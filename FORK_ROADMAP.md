carry the detail. The upstream roadmap stays in [ROADMAP.md](ROADMAP.md); this file is the fork's
own order and version policy.

- Fix history: [FORK_CHANGELOG.md](FORK_CHANGELOG.md)
- Fork versioning: [FORK_VERSIONING.md](FORK_VERSIONING.md)
- Specs index: `docs/superpowers/specs/2026-11-16-feature-plan-index.md`

Current release: **v1.4.11**, tagged `v1.4.11` and published as a GitHub release. Versions are
aligned everywhere; Tests and Release check are green, and the Standard APK, checksums and GPG
signature are attached. The unreleased challenge work below is next, not part of 1.4.11.

## План фич

Живой список: что делаем, что кандидаты, что сознательно отложено. Порядок важнее дат:
сначала маленькое и проверяемое, потом крупное. Обновляется по мере обсуждения.

**Спеки и открытые вопросы:** `docs/superpowers/specs/2026-11-16-feature-plan-index.md`
(History, What's new, недавние рутины, шорткаты, длительность, Standard APK, «свернуть подходы»,
«заменить в программе», суперсеты до 4, один подход без каскада и номер шкафчика сделаны; пауза
плана согласована; остальные — кандидаты и задачи). `fork-status`, чек-лист синхронизации и тестовая гигиена сделаны 2026-11-17.

### Принципы

- Не дублировать очередь upstream: перед стартом проверить открытые PR (#702, #509, #706,
  #610, #1207 и серию watch-драфтов).
- Один PR — одна фича. Логика в `frontend/src/lib` — чистыми функциями с тестами рядом.
- Не добавлять поля в `S`, если значение выводится из истории: sync, бэкапы и API остаются
  нетронутыми.
- Новые области — за модулем (`docs/MODULES.md`), новые строки — через `t()`.
- Local-first, без телеметрии и без обязательных внешних вызовов.

### Порядок

Исторический порядок работ, не текущий статус. Что уже выпущено и в какой версии, смотри в
разделе «Сделано по версиям» ниже; активные задачи — в «Готово к реализации» и у кандидатов.

1. **Поиск по History** — сделано в v1.4.9.
2. **What's new** — авто-шит раз за версию + ряд в Settings; v1.4.9.
3. **Недавние рутины** — в Start picker, по времени последней тренировки; v1.4.9.
4. **Шорткаты** — `?`, `/`, Esc и существующие клавиши тренировки; v1.4.10.
5. **Оценка длительности** — согласована; v1.4.10.
6. **Асимметрия L/R** — дешёвая аналитика из уже логируемых per-side данных; заодно даёт базу
   для режима травм («левая слабее на 12 %»). Кандидат.
7. **Подсказка отдыха по RIR/RPE**, **номер шкафчика** и **один подход без каскада** — мелкие
   улучшения, пока идёт работа над крупным. Номер шкафчика и один подход сделаны в v1.4.10;

   правил sync. Кандидат.
9. **Пауза плана** — отпуск/болезнь без сломанной ротации, прогрессии и streak. Кандидат.
10. **Предпросмотр бэкапа + «Проверка данных»** — доверие self-hosted аудитории. Кандидат.
11. **Каталог-audit + тестовая гигиена** — меньше повторяющихся багов и быстрее чужие PR. Тестовая
    гигиена сделана в v1.4.8 (`docs/dev/WINDOWS_TESTS.md`); каталог-audit остаётся кандидатом.
12. **`fork-status` и чек-лист синхронизации** — сделано в v1.4.8.1 (`scripts/fork/upstream-status.mjs`,

14. Native/часы — когда есть девайс под рукой. Кандидат.

### Готово к реализации

- [ ] **Челленджи: месячные медали и новые задания** — полный пакет из четырёх независимых
      этапов, чтобы выпускать по одному PR:
  - [ ] **Этап 0. Медали месяца.** 1 выполненный челлендж = бронза, 2 = серебро, 3 = золото.
        Одна медаль на месяц на полке, без изменения `S.challenges`. Спека:
        `docs/superpowers/specs/2026-11-25-challenge-tier-medals-design.md`.
  - [ ] **Этап 1. Тематические задания.** Пять новых челленджей из уже считаемых фактов
        (утро, выходные, разнообразие, рабочие подходы, кардио-сессии), новые формулировки и
        детерминированная тема месяца. Спека:
        `docs/superpowers/specs/2026-11-25-challenge-quests-design.md`.
  - [ ] **Этап 2. Бонусное бинго.** Сетка 3×3 после двух выполненных челленджей, искры за линии,
        без влияния на медаль. Спека:
        `docs/superpowers/specs/2026-11-25-challenge-bingo-design.md`.
  - [ ] **Этап 3. Возвращение.** После 14+ дней без тренировок первый месяц снова начинается с
        трёх мягких целей, медаль остаётся бронза/серебро/золото. Спека:
        `docs/superpowers/specs/2026-11-25-challenge-return-design.md`.

### Ранее согласовано и сделано

Ниже подробности по уже выпущенным пунктам, чтобы не искать их в общем порядке. Новые
согласованные задачи и кандидаты идут после этого раздела.

- [x] **Поиск по History** — строка поиска, чипы All / Workouts / Notes / Recovery / Activities,
      фильтр месяца и «только PR». Глубокий поиск: название и заметки тренировки, имена упражнений
      (локализованные и английские), заметки подходов, зал, дневные заметки, recovery, активности.
      Без новых полей в `S`. Спека: `docs/superpowers/specs/2026-11-16-history-search-design.md`.

- [x] **What's new после обновления** — авто-шит один раз на версию с 3–5 пунктами и ссылкой на
      changelog, плюс постоянный ряд в Settings → About & updates. Первая установка молчит. Спека:
      `docs/superpowers/specs/2026-11-16-whats-new-design.md`.

- [x] **Недавние рутины в Start picker** — до пяти рутин по времени последней тренировки, без
      дублей с «Today». В упражнениях остаётся «Chosen» по частоте. Спека:
      `docs/superpowers/specs/2026-11-16-recent-routines-design.md`.

- [x] **Шорткаты** — `?` открывает список, `/` фокусирует поиск текущего экрана, Esc закрывает
      шит; клавиши тренировки остаются. Без буквенной навигации. Спека:
      `docs/superpowers/specs/2026-11-16-keyboard-shortcuts-design.md`.

- [x] **Оценка длительности тренировки** — «≈55 мин» на строке рутины и дня в Plan, в превью
      перед стартом. Гибрид: медиана последних 5 завершённых сессий этой рутины (минимум 2),
      иначе расчёт по плану (подходы, отдых, кардио, warm-up, superset). Комбинированный день —
      точная история набора или сумма. Без новых полей в `S`. Дизайн согласован 2026-11-16;
      спека будет в `docs/superpowers/specs/`. Фаза 2 (потом): Home/виджет и режим «у меня
      N минут».

- [x] **Android APK: Standard** — Standard 180 px выпускается из релизов форка, со своей подписью
      и GPG-подписанными контрольными суммами. Plus/HD этим форком не выпускаются из-за лицензии
      медиа; переключатель вариантов снят. Спека:
      `docs/superpowers/specs/2026-11-17-apk-variants-design.md`.

- [x] **«Свернуть подходы»** — ряд под «Add exercise» в Cards/Focus. Активен, когда отмечены
      все подходы юнита; сворачивает карточку в однострочную сводку (та же, что в List), не меняя
      данные подходов. Кнопка-переключатель: после сворачивания — «Показать подходы». Свёрнутость
      сохраняется при уходе с экрана тренировки и возвращении (в памяти приложения), сбрасывается
      при перезагрузке. На свёрнутой карточке свайп листает упражнения и не может удалить или
      скопировать подход. Реализовано 2026-11-18. Спека:
      `docs/superpowers/specs/2026-11-18-finish-exercise-design.md`.

- [x] **«Заменить в программе»** — в шите после выбора упражнения в Swap, под «Use in this workout».
      Активна, когда запись привязана к слоту программы и сессия живая. Шит открывается на конфиге
      замены слота (сеты/повторы/вес/правило переносятся на новое упражнение); правки из шита уходят
      и в тренировку, и в слот. Суперсерия сохраняется, старое упражнение не добавляется в backups,
      Undo нет. Прошлые тренировки и редактор сохранённой не затрагиваются. Без новых полей в `S`.
      Спека: `docs/superpowers/specs/2026-11-18-replace-in-routine-design.md`.

- [x] **Суперсеты до 4 упражнений** — модель `sg` уже держит группу любой длины; снять UI-ограничение
      «только не-группа может сливаться» и растить группу из ⋯ меню участника (и из шапки, если
      включены кнопки «Make superset»). Предел 4 — тост `A superset holds up to 4 exercises` в
      сессии, редакторе рутины и Coach. «Unpair» в шапке распускает всю группу, «Remove from
      superset» в меню вынимает одного. Импортированные группы и круги не ограничиваются. Без
      новых полей в `S`. Реализовано 2026-11-19. Спека:
      `docs/superpowers/specs/2026-11-18-superset-up-to-four-design.md`.

### Кандидаты: пользовательские

- [ ] **Режим «травма / боль»** — флаг упражнения с заметкой и сроком, предупреждение в
      тренировке, автозамена из backup-упражнений, пауза прогрессии, контекст для Coach/MCP.
      Есть `dayNotes 'injured'` и `session-noprog`, но не на уровне упражнения. Средний объём.
- [ ] **Асимметрия L/R** — график и флаг разницы сторон по уже логируемым per-side данным.
      Новых данных не нужно; полезно для реабилитации и профилактики. Малый-средний.
- [ ] **Подсказка отдыха по RIR/RPE** — «+30 с?» после подхода, оценённого в RIR 0. Opt-in,
      только предложение, таймер не меняется сам. Малый.
- [ ] **Кардио-рекорды и темп** — лучшая средняя скорость/дистанция, тренд темпа, время в
      пульсовых зонах по уже сохраняемым avg/max HR. Оговорка: без per-second сэмплов «PR на
      5 км» не считается, только лучшие сессии/отрезки. Средний.
- [x] **Номер шкафчика на карточке check-in** — issue #1096. Необязательный номер в карточке зала,
      показывается на check-in и на Home для последней карты; хранится в `S.gymCards`, без нового поля.
      Реализовано 2026-11-19. Спека: `docs/superpowers/specs/2026-11-16-checkin-locker-design.md`.
- [ ] **Пауза плана** — отпуск/болезнь: не ломать ротацию, прогрессию и streak на N дней.
      Есть day notes и rest days, но явной паузы нет. Малый-средний.
- [x] **Один подход без каскада** — изменить вес одного рабочего подхода, не задевая
      следующие (issue #1166). Настройка «Weight changes apply to the following sets» в Settings →
      Fine-tuning, по умолчанию включена; выключенная оставляет вес только в изменённом подходе.
      Реализовано 2026-11-19. Спека: `docs/superpowers/specs/2026-11-16-single-set-weight-design.md`.
