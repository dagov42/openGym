# Журнал фиксов форка openGym

Этот файл ведётся только в форке [dagov42/openGym](https://github.com/dagov42/openGym).
Здесь фиксируется всё, что приходит из апстрима [DuarteSantos8/openGym](https://github.com/DuarteSantos8/openGym)
и что исправляется локально: что за баг, как проявлялся, чем починен и где лежит.

Формат записи:

```
## ГГГГ-ММ-ДД — короткое название синхронизации

### Причина / что было сломано
### Исправление
### Ссылки (PR / issue / коммиты)
### Проверка (тесты, сборка)
```

---
