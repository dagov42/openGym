# Журнал фиксов форка openGym

Этот файл ведётся только в форке [dagov42/openGym](https://github.com/dagov42/openGym).
Здесь фиксируется всё, что приходит из апстрима [DuarteSantos8/openGym](https://github.com/DuarteSantos8/openGym)
и что исправляется локально: что за баг, как проявлялся, чем починен и где лежит.

Формат записи:

```
## ГГГГ-ММ-ДД — короткое название синхронизации

### Причина / что было сломано
### Исправление
### Ссылки (PR / issue / коммиты)
### Проверка (тесты, сборка)
```

План фич и порядок: [FORK_ROADMAP.md](FORK_ROADMAP.md). Схема версий форка:
[FORK_VERSIONING.md](FORK_VERSIONING.md).

## 2026-11-25 — Поиск зала через 2GIS и Яндекс.Карты

### Что добавлено

- На экране добавления зала появились кнопки **2GIS** и **Yandex Maps**. Они открывают

  координаты и открывает редактор зала. Если в ссылке нет координат, точка ставится по текущему

  Яндекс-карточки или перетаскиванием карты/«Я здесь». Ссылка на карту сохраняется как `mapUrl`
  и открывает 2GIS/Яндекс/Google/Apple Maps в соответствующем приложении.
- API 2GIS/Яндекса не вызываются: только публичные ссылки и пользовательский буфер обмена.

## 2026-11-18 — 1.4.10: фоновая загрузка обновления и горячие клавиши

Релиз `v1.4.10` (следующий патч после опубликованного `openGym 1.4.9`).

### Причина / что было сломано

- Шит прогресса обновления открывался с `locked: true`, а `downloadAndInstall` сразу открывал
  установщик. Скрыть окно и продолжить тренировку было нельзя.

### Исправление

- `downloadUpdate` и `installDownloadedUpdate` разделены; скачивание больше не запускает установщик.
- Прогресс-шит можно закрыть; загрузка продолжается в фоне.
- После загрузки: подтверждение «Установить / Позже». Во время активной тренировки вместо модалки
  показывается toast с действием «Установить».
- Проверка SHA-256 осталась на стороне Install plugin перед установкой.
- Горячие клавиши: `?` открывает список, `/` фокусирует поиск текущего экрана, Settings → About
  получил ряд «Keyboard shortcuts».
- Session length: Plan и preview показывают `≈N мин`; медиана последних пяти exact-сессий, до
  двух сессий — оценка по плану.
- «Свернуть подходы» в Cards/Focus: кнопка-переключатель, подходы остаются отмеченными; fold
  переживает уход с экрана и возвращение, «Показать подходы» разворачивает, данные не меняются.
  Сворачивается только блок подходов: изображение, описание и меню упражнения остаются открытыми.
  Скрытие и показ блока подходов идут с короткой анимацией высоты и прозрачности.
  Переводы `Collapse sets` и `Tick every set first` добавлены во все 25 пакетов.
- «Заменить в программе» в шите Swap: меняет и текущую тренировку, и слот программы; сеты, повторы,
  вес, правило и суперсерия переезжают на новое упражнение, история и редактор не затрагиваются.
  Переводы `Replace in routine` добавлены во все 25 пакетов.
- Суперсеты до 4: группа растёт из шапки и ⋯ меню, пятый участник получает тост, `Unpair` распускает
  всю группу, `Remove from superset` вынимает одного. Круги и импортированные группы не меняются.
  Переводы новых строк добавлены во все 25 пакетов.
- «Один подход без каскада»: настройка `Weight changes apply to the following sets` в Settings →
  Fine-tuning, по умолчанию включена; выключенная меняет вес только в выбранном подходе. Переводы
  добавлены во все 25 пакетов.
- Weekly sets: переключатель «Count main muscles only» в Ranges — подход считается один раз для
  основной мышцы, без доли вспомогательных. Плюс профильный «Rest between sides» для per-side reps
  и «Effort on warm-ups» при включённом RIR/RPE. «Ask for effort before ticking» спрашивает оценку
  перед отметкой рабочего подхода. Переводы во всех пакетах.
- Per-side больше не скрывает бренды (plan chips + workout chips). Health Connect получает
  измеренные сэмплы пульса рядом с тренировкой. Wear APK теперь имеет versionCode ниже
  телефонного, поэтому случайная установка на телефон не перезаписывает приложение (#1359).
- #1247: русские названия упражнений в sentence case — «Подъём на носки и фронтальное приседание
  с гирей»; имена собственные («Арнольда», «Смита», «Жиронде») сохраняют заглавную.
- Русские названия обновлены по колонке «Ваше название» из `2026-11-18-exercise-name-translations.xlsx`
  и странице CrossFit: «машина» заменена на «тренажёр», имена Смит, Скотт, Зоттман, Свенд,
  Поликвин, Паллоф, Арнольд капитализированы; CrossFit-упражнения взяты по ID.
- #1379: «Переход к следующему упражнению» — Off / после отдыха / сразу. «Сразу» двигает маркер
  по тику, отдых продолжает идти для законченного упражнения; старый переключатель читается как
  «после отдыха». Переводы четырёх строк во всех 25 пакетах.
- Stats: подписи периодов в карточках усилия и диапазонов больше не жёстко английские — русские
  `30 д`, `90 д`, `1 г`; переводы добавлены во все 25 пакетов.
- #1164: нажатие на часы отдыха открывает полноэкранный таймер с большим кольцом, −15 с, паузой,
  +15 с и Skip; колесо времени доступно с больших часов.
- #1193: Coach сохраняет пирамиды в payload, валидации, review и fingerprint плана.
- #1375: у кардио-подхода есть часы: ▶ запускает счёт, ■/тик/Finish записывает минуты (с округлением),
  время переживает reload и не считает паузы тренировки. Кнопка часов перенесена под цифровые
  блоки, в строку рядом с «Оценить».
- P2 #1378: web-контейнер слушает IPv4 и IPv6.
- P2 #901: Explorer группирует оборудование (Body weight, Free weights, Barbells, Machines,
  Cables, Bands, Balls & rollers, Cardio machines, Bench & bar, Other), группа раскрывается на
  свои виды; переводы новых строк во всех 25 пакетах.
- P2 #1265: цель на упражнение (вес + 3/6/12 месяцев) в шите упражнения: дата, прогресс от
  лучшего веса на момент постановки, недельный прирост до цели; `S.exGoals` синхронизируется.

## 2026-11-17 — fork-status, чек-лист синхронизации и reality pass по спекам

PR форка: [#1](https://github.com/dagov42/openGym/pull/1). Спека:
`docs/superpowers/specs/2026-11-16-fork-operations-design.md` (B и C; A закрыта ранее в
тестовой гигиене).

### Причина

- `fork-status` и чек-лист синхронизации были согласованы, но не реализованы: сравнение с
  upstream делалось вручную по журналу.
- Спеки писались 2026-11-16, до реализации. После переноса плана в `FORK_ROADMAP.md` индекс
  спек всё ещё ссылался на `FORK_CHANGELOG.md`; порядок в индексе и в «Порядке» roadmap
  разошёлся; статусы не отражали сделанные Windows-тесты и fork-status.
- В `csv-mapper` и `single-set-weight` не были описаны последствия для sync, API-токенов и
  merge, а решение по локализации новых строк нигде не было зафиксировано.

### Исправление

1. **`fork-status`:** `scripts/fork/upstream-status.mjs` — read-only, четыре секции (upstream
   без форка, merged PR с пересечением файлов, локальные коммиты, вероятные конфликты),
   `--fetch`, `--json`, `--base`; точка синхронизации читается из `FORK_CHANGELOG.md`.
   Тесты: `scripts/fork/upstream-status.test.mjs` (15). Чек-лист: `docs/dev/FORK_SYNC.md`.
2. **Индекс спек:** ссылки на план теперь ведут в `FORK_ROADMAP.md`; `Order` совпадает с его
   «Порядком»; `fork-operations` помечен как сделанный; UX-кандидаты без спек — там же.
3. **Локализация:** решение записано в индекс и обе спеки — новые строки только по-английски
   через `t()`/`tn()`, пакеты локалей в PR фичи не правятся, непереведённое падает на
   английский; заголовки импортируемого файла — данные и не переводятся.
4. **csv-mapper:** `S.csvMaps` — stamped map (`csvMaps` в `STAMPED_MAPS` обоих sync-слоёв и
   parity-тест), merge по подписи, удаление — stamped tombstone; токенам доступно только
   чтение как настройка; открытые вопросы закрыты.
5. **single-set-weight:** `S.weightCascade` — обычная настройка (`edited.weightCascade`,
   последнее изменение целиком); токенам только чтение; строки через `t()`.
6. **Roadmap/README:** `fork-status`, чек-лист и тестовая гигиена отмечены сделанными;
   `scripts/README.md` получил раздел Fork maintenance.

### Проверка

- `node --test scripts/fork/upstream-status.test.mjs` — 15/15.
- `node scripts/fork/upstream-status.mjs` и `--json` на текущем репозитории: точка

Релиз `v1.4.8.1` (без префикса `fork-`), PR форка [#1](https://github.com/dagov42/openGym/pull/1).

### Причина

- Кнопка «Проверить обновления» не ходила в сеть: `checkForUpdate()` кэширует ответ на всю

## 2026-11-16 — исправления критичных issue

### #1296 — скакалка не считалась кардио

**Причина.** У rope-упражнений в каталоге `bodyPart: "full body"`, а `isCardio`
проверял только `bp === 'cardio'`. Поэтому `log_workout` отклонял минуты
(«this one takes reps or seconds»), а недельный cardio total игнорировал
записанные секунды.

**Исправление.** Восемь rope-упражнений переведены на `bodyPart: "cardio"`:
`2612`, `3675`, `3676`, `3677`, `3678`, `3885`, `4829`, `5038`. Пересобраны
`exercises-data.js`, coach library и browse-страницы каталога. `6100`
(bodyweight skipping, без скакалки) остался сетами/повторами.
`cardio-reps.test.js` обновлён под новое поведение.

**Заодно.** `scripts/catalogue/validate.mjs` теперь знает поле `assisted`
(появилось в #1222, из-за него `build.mjs --check` падал на `3235.json`).

### #1268 — iPhone отклонял фото из библиотеки

**Причина.** `sniffKind` узнавал только часть HEIF-брендов. 10-битный HEIC
(`heix`), HEVC-последовательности (`hevx`, `hevm`, `hevs`), `mif2`, `avci`
и бренды в верхнем регистре возвращали `null`, и `ingestMediaFile` кидал
`MediaError('type')`. Тот же код используется аватаром.

**Исправление.** Полный список брендов ISO/IEC 23008-12 плюс `avci`, а HEIF
сравнивается без учёта регистра. Тест добавлен в `media-sniff.test.js`.

**Ограничение.** DNG/ProRAW браузер по-прежнему декодировать не умеет: такой
файл даст «unreadable», а не «type». Для обычных HEIC/AVIF из фотоальбома
путь открыт.

### #1290 — Coach обрывал соединение при уходе в фон

**Причина.** Транспортная ошибка при долгом ожидании ответа провайдера
(`Software caused connection abort` после ~63 с) сразу завершала job, хотя
запрос мог быть оборван транзиентно (смена сети, NAT, уход приложения в фон).

**Исправление.** Один повтор запроса, если соединение оборвалось после ≥ 5 с
ожидания и job не отменён. Мгновенные отказы (DNS, unreachable) не ретраятся,
чтобы не удваивать ожидание. Тесты в `api/test/adapters-http.test.js`.

### #1251 — ChatGPT-коннектор отклонялся

**Причина.** CIMD-документ ChatGPT объявляет
`token_endpoint_auth_method: "private_key_jwt"`, но перечисляет `none` в
`token_endpoint_auth_methods_supported`. Сервер принимал только `none`.

**Исправление.** Публичным считается клиент, у которого declared `none` **или**
`none` есть в списке поддерживаемых методов. Клиент только с `private_key_jwt`
по-прежнему отклоняется.

### #1297 — Gemini не регистрировался (DCR)

**Причина.** `registerClient()` ограничивал `redirect_uris` пятью адресами,
а Google присылает шесть (по одному на surface).

**Исправление.** Лимит поднят до 10, как у client metadata document; сообщение
об ошибке обновлено.
